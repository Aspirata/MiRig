# MiRig

[![License: CC0](https://img.shields.io/badge/License-CC0-brightgreen.svg)](./LICENSE)

**Русский** · [English](README.en.md)

MiRig — экспериментальный риг для Blender без костей, драйверов, аддонов и встроенных Python-скриптов. Вся деформация реализована с помощью Geometry Nodes.

> [!WARNING]
> MiRig - пародия на риг из Mine-imator. Он не претендует на качество или пригодность для серьёзной работы: это эксперимент-шутка, цель которого — воспроизвести в Blender всю ту самую говняшность рига из Mine-imator

Риг создан исключительно ради шутки с помощью **ChatGPT 6 Astra**.

**Обзор MiRig в моём Telegram-канале:** https://t.me/Aspirata_dev/104

## Требования

- Blender 4.3 или новее.

## Как использовать

1. Скачайте репозиторий и откройте `MiRig.blend` в Blender.

## Особенности

- Плавное сгибание тела по трём осям.
- Никаких зависимостей, кроме Blender.
