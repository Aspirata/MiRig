# MiRig

[![License: CC0](https://img.shields.io/badge/License-CC0-brightgreen.svg)](./LICENSE)

[Русский](README.md) · **English**

MiRig is an experimental rig for Blender with no bones, drivers, add-ons, or embedded Python scripts. All deformation is handled by Geometry Nodes.

> [!WARNING]
> MiRig is a parody of the rig from Mine-imator. It's not meant to be polished or suitable for serious work - it's a joke experiment made to recreate the exact same shittiness of the Mine-imator rig inside Blender

The rig was made purely as a joke with the help of **ChatGPT 6 Astra**.

## Requirements

- Blender 4.3 or newer.

## How to use

1. Download the repository and open `MiRig.blend` in Blender.

## Features

- Smooth body bending along three axes.
- No dependencies other than Blender.
